# Golden Set fixtures (§57)

Synthetic, clearly-labelled **TEST FIXTURE** documents used by automated tests to measure separate axes:
text accuracy, Arabic extraction defects, page labels vs file order, OCR of image-only pages, reading order
(two columns), tables with merged headers and units, diagrams with arrows, multi-page questions, renumbered
sections with separate answer keys, negation (NOT / EXCEPT), units/values, missing keys, unofficial marks
(circled option), exact vs near duplicates, DOCX paragraph locators, PPTX slide numbers, ZIP image sets.

* **Origin:** authored by hand for structural testing; generated by `tools/fixtures/build-fixtures.mjs`
  (DOCX via `docx` → PDF via LibreOffice; images via Chromium; PDF assembly via `pdf-lib`).
* **Not a medical reference.** Sentences are generic teaching-style statements chosen to exercise the
  pipeline. They must never be shown to the owner as study material or used as evidence outside tests.
* **Ground truth:** [`expected.json`](expected.json) — written together with the generator and checked by the
  orchestrator against `pdftotext`/`pdfinfo` output of the generated files (page counts, printed labels,
  question pagination, keys). `known_extraction_defects` documents real defects in the raw PDF text layer that
  the pipeline must normalize or flag.
* **Regenerate:** `npm run fixtures` (needs LibreOffice and Chromium). Regenerated binaries may differ byte-wise;
  tests assert on structure and text, not on hashes.
